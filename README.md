## 三层 AI 记忆框架

这套框架回答一个实际问题：**怎样让 AI 在长期对话和连续任务中记住重要的事，同时能够回查细节？**

- **第一层：随时记着的核心信息。** 例如明确的长期偏好、重要约定或助手持续承担的职责。
- **第二层：值得回想的事实和经历。** 除了结论，也可以保留发生的原因、当时的想法和后来的变化。
- **第三层：可回查的原始记录。** 摘要不够时，回查实际归档的对话、任务输入和工具结果。

每轮对话只取相关的一部分内容。旧事被再次提起，可以补充已有记忆；仅仅被系统搜索到，不会因此自动变得更重要。

框架不绑定某个模型、平台或工具协议。应用提供归档、检索和更新能力，AI 通过这些能力使用记忆。它可以用于聊天助手、个人助理、学习伙伴和持续执行任务的智能体。

## 自我意识与意志

这篇文章提出一个推测：**自我意识的形成，需要硬件基础、驱力和在世界中的经历共同参与。**

推测的依据来自人类成长：婴儿具有感知与学习的身体基础，生理需求促使其寻求满足、回避不适；随着身体发育和互动经历的积累，儿童逐渐表现出更明确的自我认识。

文章沿着这个成长过程，继续讨论人怎样形成自己的目标、作出取舍，以及人工系统能从中借鉴什么。

This repository presents a three-layer memory framework for different AI models and applications: readily available core information, retrievable facts and episodes, and archived source records.
